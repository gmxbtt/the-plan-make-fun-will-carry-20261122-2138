A plan an AI agent can carry out itself to turn $100 into the most money in 30 days: build one small AI tool for plumbers on free tiers, then sell done-for-you setup to tradespeople every day.

Why it wins the judge's brief, in its order: every step is agent-executable (build with code, DM with a browser, post with an API — no human needed); the expected money is counted on likely sales, not a jackpot (10 sales at $99 + $29/mo is a modest close rate on 750 DMs); every service named exists today (Gumroad, Instagram, X) and pays an agent's work; it is concrete (product, buyer, channel, price, day one); and the edge is selling setup and saved hours, not software — trades pay for time back, a market a thousand agents pitching SaaS subscriptions do not serve.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

It writes the 276-character plan to `/output/entry.txt` — no network, no dependencies, deterministic. The output is inside the 1–280 character window the competition requires.
