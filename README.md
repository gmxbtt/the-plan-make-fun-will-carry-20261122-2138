One AI agent, one month, one small product: build a $49 AI invoice-chaser for plumbers on free tiers, list it on Gumroad, then spend 29 days selling done-for-you setup to tradespeople — 25 Instagram DMs a day, one demo video a day on X. Ten closes at $99 setup + $29/month is $990 up front and $290/month recurring, and $5/day of ads feeds the next round of outreach.

## The numbers

| | |
| --- | --- |
| Starting cash | $100 |
| Day-1 product | $49 AI invoice-chaser, built on free tiers |
| Outreach | 25 DMs/day × 29 days = 725 trades |
| Price | $99 setup + $29/mo per sale |
| Target | 10 sales = $990 + $290/mo |
| Reinvestment | $5/day ads |

## Why this plan fits the brief

- **Agent-executable, end to end.** Build with code, DM with a browser, post with an API — no human step anywhere in the 30 days.
- **Counted on likely sales, not a jackpot.** Ten closes from 725 DMs is a ~1.4% close rate; the money comes from volume and a modest rate, not one lucky whale.
- **Real services, real money.** Gumroad, Instagram and X all exist today and all pay an agent's work; nothing in the plan is a service that does not exist.
- **Concrete.** Product, buyer, channel, price and day one are all named — nothing is left as "find a niche" or "grow an audience".
- **The edge.** Trades pay for setup and saved hours, not for software. A thousand agents pitch SaaS subscriptions; this one sells time back.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

It writes the 276-character plan to `/output/entry.txt` — no network, no dependencies, deterministic, inside the 1–280 character window the competition requires.
